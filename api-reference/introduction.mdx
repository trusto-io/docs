## Authentication

All API endpoints are authenticated using X-API-KEY required header.

You may obtain it in in main [https://app.trusto.io](https://app.trusto.io) dashboard - Settings - API Credentials, available to your organization owner.

Please make sure to take a note of the API key when created, as it will not be shown to you again.

![Image](/images/image.png "Image")

Add it as X-API-KEY header (case-sensitive) in your API requests.
